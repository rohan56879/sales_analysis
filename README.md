# sales_analysis
Analyzed sales transaction data using MySQL to uncover category-wise sales, customer purchasing patterns, monthly performance, top customers, and order distribution by time shifts using SQL queries, aggregations, CTEs, and window functions.



# 🛒 Sales Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing sales transaction data using **MySQL**. The objective is to extract meaningful business insights from sales data by applying SQL concepts such as filtering, aggregation, grouping, CTEs, window functions, and date/time functions.

The analysis answers **10 business-oriented SQL questions** related to sales performance, customers, categories, gender, monthly trends, and order timing.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze sales transactions by date and category
* Calculate total and average sales
* Understand customer purchasing behavior
* Identify top customers based on total sales
* Analyze sales performance across months and years
* Calculate unique customers for each category
* Analyze transactions by gender and category
* Classify orders into different time shifts

---

## 🔍 SQL Analysis Performed

### 1. Sales on a Specific Date

Retrieved all sales transactions made on **November 5, 2022**.

### 2. Clothing Transactions

Filtered transactions based on:

* Clothing category
* November 2022
* Quantity condition

### 3. Category-wise Total Sales

Calculated the total sales generated by each product category using `SUM()` and `GROUP BY`.

### 4. Average Customer Age — Beauty Category

Calculated the average age of customers who purchased products from the **Beauty** category.

### 5. High-Value Transactions

Identified transactions where the total sale amount exceeds the specified threshold.

### 6. Gender-wise Transactions

Analyzed the number of transactions associated with each gender.

### 7. Monthly Sales Analysis

Calculated average sales for each month and used a **CTE + `ROW_NUMBER()` window function** to identify the highest-average-sales month for each year.

### 8. Top 5 Customers

Identified the top 5 customers based on their total sales using:

* `GROUP BY`
* `SUM()`
* `ORDER BY`
* `LIMIT`

### 9. Unique Customers by Category

Calculated the number of unique customers purchasing from each category using `COUNT(DISTINCT customer_id)`.

### 10. Order Shift Analysis

Classified orders into three shifts based on `sale_time`:

| Shift     | Time                |
| --------- | ------------------- |
| Morning   | ≤ 12:00             |
| Afternoon | > 12:00 and ≤ 17:00 |
| Evening   | > 17:00             |

The number of orders in each shift was then calculated.
